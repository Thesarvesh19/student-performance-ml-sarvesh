# 🎓 Student Performance Prediction using Machine Learning

## 📌 Overview
This project focuses on predicting student performance based on factors such as **study hours, sleep hours, and attendance** using Machine Learning techniques.

The goal is to understand how different factors affect academic performance and build a model that can make accurate predictions.

---

## 🚀 Features
- 📊 Data Analysis & Visualization  
- 🧹 Data Cleaning & Preprocessing  
- 🤖 Machine Learning Model (Linear Regression)  
- 📈 Model Evaluation (R² Score & MAE)  
- 🔍 Insights from real-world dataset  

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Scikit-learn  
- Jupyter Notebook

## ⚙️ Workflow
1. Load dataset  
2. Explore data (EDA)  
3. Clean and preprocess data  
4. Visualize relationships between variables  
5. Train Linear Regression model  
6. Evaluate model performance  
7. Predict student scores  

---

## 📊 Key Insights
- 📈 Strong positive relationship between **study hours and student scores**  
- 📉 Sleep hours and attendance also impact performance  
- 🤖 Model successfully predicts student scores with good accuracy
